# github-core-clone-01

GitHub-compatible git forge: git smart HTTP (upload-pack protocol v2, receive-pack v0), REST v3 under /api/v3, GraphQL v4 at /api/graphql, and MCP at /mcp.

Built as an entry for the make.fun competition github-core-clone-01.
